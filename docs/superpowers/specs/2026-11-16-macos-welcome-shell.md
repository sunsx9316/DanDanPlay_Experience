# macOS Windows 式欢迎页 / 主页设计（P5）

> 状态：已实现并合并 win-porting（2026-11-16），替代原先的品牌启动页。
> 参考：Windows `AcplayWPFClient/Pages/Welcome/Welcome.xaml` 及其子页面
> 范围：macOS；iOS/tvOS 行为不变。

## 1. 定位

macOS 的启动页不是单纯的品牌欢迎页，而是 Windows 版的「欢迎/主页外壳」：

```text
┌──────────────┬──────────────────────────────────────┐
│ 侧边导航      │ 内容区（Overview / 公告 / 未看 / 时间表 │
│ 首页          │ / 排行榜 / 继续播放 / 在线观看）       │
│ 公告          │                                      │
│ 未看番剧      │                                      │
│ 新番时间表    │                                      │
│ 排行榜        │                                      │
│ 继续播放      │                                      │
│ 在线观看      │                                      │
│              │                                      │
│ 登录/个人中心 │                                      │
└──────────────┴──────────────────────────────────────┘
```

侧边栏固定宽度约 200pt；右侧内容区随窗口缩放。主窗口保留该外壳，视频在独立播放器窗口打开（P3）。

## 2. 侧边导航

| 顺序 | 入口 | 说明 |
|---|---|---|
| 0 | 🏠 首页 | Overview 概览 |
| 1 | 📢 公告 | 完整公告列表 |
| 2 | 📺 未看番剧 | 追番队列简介与详情 |
| 3 | 📆 新番时间表 | 季度/星期/搜索筛选 |
| 4 | 🔥 排行榜 | 复用现有 `TrendingViewController` |
| 5 | ⏯️ 继续播放 | 本地最近播放（最多 10 条） |
| 6 | 📺 在线观看 | 在线资源搜索与结果 |

底部：
- 未登录：登录弹弹play。
- 已登录：个人中心 + 会员状态文案，可进入现有会员中心。
- 选中项使用强调色半透明背景；悬停有反馈。

## 3. 首页 Overview

按 Windows 顺序展示卡片，模块可整块隐藏（无数据时不占位）：

1. **继续播放**（`IsLastPlayVisible`）
   - 最多 3 条横向卡片；缩略图/标题/“播放到 mm:ss”/日期。
   - 点击卡片恢复本地文件与进度；点击标题进入“继续播放”完整页。
2. **最新公告**（`IsBannerVisible`）
   - 只展示第 1 条公告的标题与描述；点击进入公告页；有 URL 时可打开浏览器。
3. **主功能按钮**
   - 打开文件（本地文件选择器，可与拖拽并存）。
   - 在线观看（切到在线观看页）。
   - 播放列表（打开播放器窗口并直接显示播放列表；没有播放器时创建空播放器窗口）。
   - 远程访问（复用现有网络文件浏览）。
   - 可选：网页嗅探/串流播放首期不做，避免承诺未实现能力。
4. **未看番剧**（`IsBangumiQueueIntroVisible`）
   - 横向卡片：海报、标题、最新一集、更新描述；刷新按钮；点击进入作品详情；标题进入完整未看页。
5. **今日新番**（`IsBangumiVisible`）
   - 海报网格（约 130x220），评分角标、已关注标记、标题；按“已关注优先 + 标题”排序。
   - 右上搜索框：按标题过滤当前列表；回车进入完整搜索结果/新番时间表。
   - 点击作品进入详情；标题进入完整时间表。

离线/未登录：继续播放、打开文件、最近播放仍可用；在线模块显示明确空态或“登录后查看”，不阻塞播放。

## 4. 子页面

### 4.1 公告
- 列表：图片、标题、描述、日期；点击有 URL 的条目打开浏览器。
- 空态：“暂无公告”；加载失败可重试。
- 数据：`/homePage` 的 `banners`。

### 4.2 未看番剧
- 列表：`/bangumi/queue/intro` 的 `bangumiList`（海报、标题、最新集、描述、更新日期、连载状态）。
- 顶部“查看全部”进入队列详情（P4 已实现的 `/bangumi/queue/details` 页面）。
- 支持刷新、空态、登录门禁。

### 4.3 新番时间表
- 季度选择：连载中的新番 + `/homePage` 返回的季度列表。
- 星期 Tab：周一至周日 + 已关注 + 全部；默认今天。
- 搜索框：标题过滤；清空恢复当前 Tab。
- 海报网格：评分、关注/取消关注（复用 P4 的收藏接口）、点击详情。
- 网格按阅读顺序逐行排列，同一行顶部对齐，末行从左侧连续开始；175pt 目标列宽，1100pt 窗口下为 166pt。
- 标题单行截断并保留完整 tooltip，标题/收藏按钮/状态使用明确约束，卡片高度与真实内容一致。
- 数据：`/homePage` 的 `shinBangumiList`、`shinBangumiOfCurrentSeason`、`shinBangumiOfPreviousSeason`；切换季度可调 `/bangumi/shin`、`/bangumi/season/anime/{year}/{month}`。

### 4.4 排行榜
- 直接嵌入现有 `TrendingViewController`（热播/飙升/新番，周期/季度，关注切换，详情跳转）。
- 使用逐行规则网格和 150pt 目标列宽，随窗口自动增减列数；1100pt 窗口下七列、海报约 141pt。
- 标题单行截断，排名使用 15pt semibold，热度使用 11pt 次要文字；热度行与状态行保持统一基线。

### 4.5 继续播放
- 最多 10 条；显示标题、播放进度、播放日期、文件目录。
- 点击继续播放；可单条移除、清空（二次确认）。
- 数据：本地 `WelcomeRecentStore`（security-scoped bookmark），不引入数据库。
- 与服务端 `/playhistory` 的关系：本地列表负责“从哪一帧继续”，服务端列表负责跨设备“看过哪些”；首期不强行合并，避免重复。

### 4.6 在线观看
- 现已在首版基础上补齐源规则、连续播放、独立媒体嗅探窗口和源置顶；详见
  `2026-11-16-macos-online-viewing.md`。
- 支持 Animeko CSS→XPath / JSONPath 与 Kazumi XPath / API 规则；Kazumi 的 API/POST、JSONPath、
  嵌套/分隔剧集见 `2026-11-16-macos-batch-2.md` §4，Animeko JSONPath 与 JSONPath 扩展见
  `2026-11-17-macos-batch-3.md` §6。
- 搜索框只在 Return 或点击「搜索」时请求；在线播放前先弹出「选择弹幕库」，选定后开始播放。
- 搜索免费；播放走 `.onlinePlayback` 会员门禁，嗅探走 `.mediaSniffer`。
- 不实现网页内嵌登录、DRM/验证码绕过；解析失败必须明确提示并可重试/换源，不伪造结果。

## 5. 状态与错误

- 每个在线模块独立加载、独立失败，不因一个接口失败导致整页空白。
- 登录失效：跳登录，返回后自动重试一次。
- 网络失败：模块内显示错误与“重试”，保留其他模块内容。
- 所有在线请求走 `AuthenticatedAPIClient`；不发送 `X-AppId/X-Signature`。
- 不在首页自动请求付费/AI 接口。

## 6. 可访问性与测试

- 常量集中在 `AccessibilityID.WelcomeShell.*`：导航项、各卡片、列表、刷新、搜索框、空态。
- L0：首页数据映射、季度/星期分组、排序、最近播放去重、搜索过滤。
- L2：打开文件 -> 独立播放器窗口播放 -> 返回主窗口外壳仍在。
- L3（AX）：7 个导航项可达、首页关键卡片可达、切换页面标题变化。
- 三平台 Debug 编译；macOS Release 编译。

## 7. 实施顺序

1. 外壳与导航（先接现有数据，空态可先用占位）。
2. Overview 四个模块。
3. 公告、未看、时间表、继续播放。
4. 在线观看首版。
5. 测试、截图、深浅色、窗口缩放。

## 8. 实现结果（2026-11-16）

- 新增 `Mac/AniXPlayer/Features/WelcomeShell/`：外壳、侧边栏、Overview、公告、未看、时间表、排行榜容器、继续播放、在线观看、详情/队列窗口 presenter。
- `PlayerLaunchViewController` 成为薄壳，承载 `WelcomeShellViewController`，保留原有回调语义。
- 继续播放通过 `onResumeFiles(files:startWith:progress:)` 把最近播放进度传给独立播放器窗口，并在时长就绪后自动跳转；已实测从 15% 续播。
- AX 冒烟已更新为检查 `nav.home` 与 7 个导航项、`overview.openFile`、`player.window`。
- 已知限制：公告模型没有日期字段；Kazumi API/POST、JSONPath 已补，但 `mgnacg` 这类
  「API 搜索 + XPath 选集 + sourceTemplate 为空」规则仍无法安全构造详情地址；真实源成功率需要手工回归。
