## 2. 在线观看

### 2.1 现状

- 源配置：
  - Animeko `css1.json`、Kazumi `index.json + rules`；
  - 7 天 TTL、强制刷新、单源失败回退缓存、原子写、8 MB 限制；
  - 缓存在 `Application Support/AniXPlayer/OnlineSources/`；
  - 默认远端地址可改，App 不内置第三方源。
- 解析：
  - Animeko CSS→XPath（`a`/`indexed`、`index-grouped`/`no-channel`）、Kazumi XPath；
  - 关键词处理、剧集排序/过滤、去重并保留同集备用线路；
  - `matchVideoUrl`/嵌套 URL/headers/cookies；Kazumi 默认 m3u8/mp4 正则；
  - 规则失败时按扩展名扫描整页 URL；`player_aaaa.url` 支持 base64 + percent 解码。
- 播放：
  - `OnlineEpisodeFile` + `File.httpHeaders` + VLC/MPV 请求头注入；
  - 播放前 Range 验证，401/403 不交给播放器；
  - 主线路失败自动尝试备用线路；
  - 虚拟文件不改本地哈希，`MatchNetworkHandle` 用「作品名 + 剧集名」+ 空 MD5 文件名匹配弹幕，不写空哈希全局缓存。
- 连续播放：
  - 默认预取当前集 + 后续 2 集；
  - 播放推进时由 `OnlinePlaybackSession` 滚动追加后续剧集；
  - 后续集解析失败会跳过并继续扫描，当前集失败仍弹错并可「重试当前集」；
  - 可在在线页关闭「连续播放」。
- 独立媒体嗅探窗口：
  - 可见 `WKWebView`，支持地址栏、前进/后退/刷新/停止、候选列表、复制、浏览器打开、播放；
  - 复用自动嗅探的 JS hook（fetch/XHR/setAttribute/video/iframe/performance/内联脚本）；
  - 播放前 Range 验证，401/403 保留候选并提示；
  - 走 `.mediaSniffer` 会员门禁，单例窗口；
  - 入口：功能菜单「媒体嗅探…」和在线页按钮。
- 自动嗅探：
  - 离屏 WKWebView + JS hook；
  - 广告候选降权/丢弃，低分候选不返回；
  - 默认 12 秒超时，首候选后 4 秒择优。
- 源置顶：
  - 源管理可星标；搜索排序置顶；结果/源管理显示置顶标记；
  - 启用/禁用、改地址、清缓存保持不变。
- 门禁：搜索登录可用；播放 `.onlinePlayback`，嗅探 `.mediaSniffer`。

### 2.2 验证与已知限制

已验证（2026-11-16 之前）：

- 应用内加载 28 个源（Animeko 18 / Kazumi 10）；
- 搜索「葬送的芙莉莲」得到 31 个结果，单源失败隔离；
- 叽哔动漫/番茄动漫的 m3u8 Range 验证 200，主线路 TLS 失败后自动切换备用线路，播放器成功播放 24:00 视频；
- 稀饭动漫直链 401，被播放前验证拦截并提示换源；
- Kazumi 7sefun 搜索/剧集成功，动态播放页嗅探过滤了广告但未拿到真实媒体地址，返回明确失败。

本轮验证：

- macOS Debug 编译通过；
- 连续播放、独立嗅探窗口、源置顶为编译验证，未跑联网/UI 功能测试。

限制：

- WKWebView 无法像 WebView2 一样拿到全部请求头；强防盗链/Cookie 站点可能失败。
- `blob:`/MSE/DRM、验证码、强反爬站点无法解析。
- Kazumi API/POST 模式规则、Animeko JSONPath 搜索暂不支持。
- 没有 GCDWebServer 本地代理转发完整请求头。
- 连续播放只滚动预取后续剧集；一次性解析整季、并发预取尚未做。
- 搜索结果置顶已做；独立搜索历史面板、来源收藏夹尚未做。
- 当前直接使用远端默认地址；分发前仍需产品/法务确认默认地址策略。

### 2.3 后续

1. Kazumi API/POST 模式、Animeko JSONPath。
2. 必要时用 GCDWebServer 本地代理转发完整请求头。
3. 并发预取/更长的连续播放队列；独立搜索历史面板。
4. 动态站嗅探成功率按真实站点继续校准。

## 3. 下载中心

### 3.1 现状

- HTTP：
  - 真实 `URLSessionDownloadTask`，进度/速度/ETA、2xx 校验、文件名冲突、暂停/续传/停止/删除；
  - 使用 background `URLSession`；下载窗口关闭后继续；
  - 启动时 `getAllTasks` 重连任务，按 UUID 映射，迟到的完成/失败事件可从持久化快照恢复；
  - 通知仍保证每个状态只发一次。
- BT：
  - 真实 Transmission JSON-RPC（session/torrent-add/get/start/stop/remove、409 重试、magnet/metainfo、files-wanted/unwanted、文件优先级）；
  - 未检测到 daemon 时不落库；
  - 远程 `.torrent` URL 预取计算 infoHash，按 `btih:` 去重；失败回退 URL。
- 任务与 UI：
  - SQLite 持久化、启动恢复、添加/设置 sheet、完成文件播放；
  - 系统入口：`magnet:`/`ddplay:`/`.torrent`；AppDelegate 打开/复用下载中心并预填；拖拽/剪贴板添加；
  - BT 引导：检测/重试/复制安装命令/官网/RPC 设置/测试连接；
  - 通知：完成/失败、点击定位任务、Dock badge、开关；
  - 队列：HTTP+BT 统一并发、全部暂停/继续、按 infohash/hash/URL 去重；
  - 状态：完成不可重启、缺失文件状态、HTTP 标题更新、无变化不刷 UI、多文件自然顺序播放、启动/暂停/删除竞态防护。
- RSS：
  - RSS 2.0 / Atom 订阅；标题、URL、自动下载开关、关键词过滤；
  - 订阅列表、添加/删除、刷新、条目列表、手动下载；
  - 自动下载仅处理未见过且匹配关键词的 enclosure 条目，每次刷新最多 20 条；
  - 持久化；默认关闭自动下载。
- 传输限制与路径：
  - 全局下载/上传限速、做种比例设置，按需 `session-set` 并显示成功/失败；
  - 远程→本地路径映射用于 BT 任务的播放/在 Finder 中显示；
  - 空映射时保持本地行为。
- 默认目录 `~/Downloads/AniXPlayer`；新增下载 AX 标识。
- 验证：`DownloadTests` 40 个通过。

### 3.2 仍待处理

1. **BT 开箱不可用**：仍依赖外部 `transmission-daemon`；没有内置引擎。发布前必须决策：外部 daemon 第一等公民，或捆绑 libtorrent/Transmission。
2. **App 终止后不自动重开**：background session 可在窗口关闭后继续；App 被终止后需要用户重新打开 App 才能重连/收敛后台任务。
3. **边下边播仍不做**：没有本地 Range 代理/piece 感知；多文件播放已按自然顺序。
4. **RSS 没有周期刷新/站点规则**；没有任务重命名/复制源/历史。
5. **真实 Transmission/RSS 未联调**；随机崩溃/网络异常恢复仍需真实环境验证。
6. **远程路径映射只覆盖 BT**；HTTP 任务仍按本机路径处理。
7. **做种/分享率/限速已有基础设置**，但没有完整的做种策略/替代限速/任务优先级队列。
8. **BT 内核捆绑未决策**（GPL/体积/签名/公证）。

### 3.3 建议顺序

1. 真实 Transmission/BT 联调（转发端口、队列、文件选择、断线重连）。
2. BT 内核捆绑决策；若不做，明确外部 daemon 的产品边界。
3. App 终止后的后台任务自动重开/恢复。
4. RSS 周期刷新、站点规则、任务历史/重命名。
5. 边下边播（若产品重新评估）。

## 4. 本地媒体库

### 4.1 现状

数据库/扫描/匹配/播放都是真的，本轮补齐了体验层：

- 扫描与匹配：
  - SQLite + 文件夹 security-scoped bookmark、递归扫描、增量扫描；
  - 前 16MB MD5 + `/match`；
  - 重扫时 size+mtime+hash 未变化则保留匹配元数据/海报/标题；内容变化才清空；
  - 缺失文件恢复且内容未变时保留匹配。
- 匹配修正：
  - 手动「匹配修正」：Bangumi 搜索 → 番剧 → 剧集 → 保存；
  - 支持取消匹配；
  - 多候选/失败不再直接丢弃；分组/多选时用目标文件选择器。
- 缺失文件：
  - `.missing` 过滤器、摘要计数、显示缺失开关；
  - 只清理缺失记录（按文件夹/全部）；
  - 缺失文件禁用播放/Finder。
- 浏览与批量：
  - 排序（标题/文件名/大小/路径）持久化；
  - 多选海报墙；单击选择、双击/播放激活；
  - 批量重新匹配、取消匹配、Finder 定位、移出媒体库、清理缺失。
- 剧集分组：
  - 已匹配文件按 `animeId` 合成一张卡：海报、标题、集数、总大小、缺失数；
  - 剧集 sheet 支持单集播放、播放全部、按集数排序；
  - 未匹配文件保持单卡，不做启发式合并。
- 缩略图/元数据：
  - 后台 AVFoundation 生成缩略图、时长、分辨率；
  - 内存 + 磁盘缓存，DB 持久化；
  - cell 复用取消；不支持的编码回退远程海报/扩展名占位。
- 扫描/权限：
  - 目录枚举和哈希等待支持取消（哈希 20 秒上限，0.1 秒轮询）；
  - 嵌套文件夹保留原 folderId，重叠添加警告；
  - 扫描/播放权限失败提示「重新选择文件夹…」并刷新 bookmark；
  - 播放只检查选中文件，不再主线程全量 `fileExists`。
- 验证：`LocalLibraryTests` 31 个通过。

### 4.2 仍待处理

1. **已看/未看标记**：媒体库 schema 没有观看数据源，未伪造；后续接播放历史。
2. **MKV/HEVC/AV1 缩略图**：当前只有 AVFoundation，失败回退海报；无 MPV 抓帧兜底。
3. **分页/局部刷新**：仍以全量查询/全量 reload 为主；大库性能需分页或快照。
4. **FSEvents/重命名跟踪**：没有实时文件监控。
5. **磁盘缩略图缓存没有 LRU 清理**；播放 security-scoped access 保留到进程退出。
6. **完整英文 localization**：新增字符串已本地化，旧 LocalLibrary 字符串仍有中文硬编码。
7. **批量多集重映射**：一次只改一个目标文件；没有整组批量重映射。
8. **远程源不扩展**：仍保留 SMB/WebDAV/FTP/Emby/Jellyfin/PC，不加 OneDrive/Plex/SFTP。

### 4.3 建议顺序

1. 已看/未看 + MKV/HEVC/AV1 缩略图。
2. FSEvents/重命名 + 分页/局部刷新 + LRU。
3. 批量重映射/整组编辑。
4. 旧字符串完整本地化。
5. 远程源按需求再评估。

## 8. 验收边界

- 每阶段必须 macOS Debug 编译通过；共享代码改动再跑 iOS/tvOS。
- 在线源不内置第三方站点；用户导入/配置，失败不伪造结果。
- 连续播放后续集失败会跳过；当前集失败必须提示并可重试。
- BT 未配置/未安装时继续明确提示，不创建假任务。
- RSS 自动下载必须由用户显式开启，且只处理匹配条目。
- 媒体库匹配修正不得伪造结果；缺失清理只删除缺失记录。
- 会员门禁以服务端权益为准；GIF/在线观看/嗅探均走统一 `EntitlementGate`。
