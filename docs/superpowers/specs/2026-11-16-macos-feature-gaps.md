## 2. 在线观看

### 2.1 现状（2026-11-16 已实现）

- `WelcomeOnlineViewController` 已重写：源筛选、跨源搜索、结果/剧集、播放、取消、源管理、合规提示。
- 源配置：
  - Animeko `css1.json`、Kazumi `index.json + rules`；
  - 7 天 TTL、强制刷新、单源失败回退缓存、原子写、8 MB 限制；
  - 缓存在 `Application Support/AniXPlayer/OnlineSources/`；
  - 默认远端地址可改，App 不内置第三方源。
- 解析：
  - Animeko CSS→XPath（`a`/`indexed`、`index-grouped`/`no-channel`）、Kazumi XPath；
  - 关键词处理、剧集排序/过滤、去重并保留同集备用线路；
  - `matchVideoUrl`/嵌套 URL/headers/cookies；Kazumi 默认 m3u8/mp4 正则；
  - 规则失败时按扩展名扫描整页 URL；`player_aaaa.url` 支持 base64 + percent 解码。
- 播放：
  - `OnlineEpisodeFile` + `File.httpHeaders` + VLC/MPV 请求头注入；
  - 播放前 Range 验证，401/403 不交给播放器；
  - 主线路失败自动尝试备用线路；
  - 虚拟文件不改本地哈希，`MatchNetworkHandle` 用「作品名 + 剧集名」+ 空 MD5 文件名匹配弹幕，不写空哈希全局缓存。
- 嗅探：
  - 离屏 WKWebView + fetch/XHR/setAttribute/video/iframe/performance/内联脚本 hook；
  - 广告候选降权/丢弃，低分候选不返回；
  - 默认 12 秒超时，首候选后 4 秒择优。
- 门禁：搜索登录可用；播放走 `EntitlementGate.require(.member, feature: .onlinePlayback)`。

### 2.2 验证与已知限制

已验证：

- 应用内加载 28 个源（Animeko 18 / Kazumi 10）；
- 搜索「葬送的芙莉莲」得到 31 个结果，单源失败隔离；
- 叽哔动漫/番茄动漫的 m3u8 Range 验证 200，主线路 TLS 失败后自动切换备用线路，播放器成功播放 24:00 视频；
- 稀饭动漫直链 401，被播放前验证拦截并提示换源；
- Kazumi 7sefun 搜索/剧集成功，动态播放页嗅探过滤了广告但未拿到真实媒体地址，返回明确失败。

限制：

- WKWebView 无法像 WebView2 一样拿到全部请求头；强防盗链/Cookie 站点可能失败。
- `blob:`/MSE/DRM、验证码、强反爬站点无法解析。
- Kazumi API/POST 模式规则、Animeko JSONPath 搜索暂不支持。
- 没有独立媒体嗅探窗口、在线播放列表/自动下一集/切集重新解析。
- 搜索结果未做来源收藏/置底；搜索历史已记录但未展示。
- 当前直接使用远端默认地址；分发前仍需产品/法务确认默认地址策略。

### 2.3 后续

1. 独立媒体嗅探窗口（`.mediaSniffer`）。
2. 在线播放列表/自动下一集：保存剧集页 + 源快照，切集时重新解析。
3. 源偏好/置底/收藏、搜索历史 UI。
4. Kazumi API 模式、Animeko JSONPath。
5. 必要时用 GCDWebServer 本地代理转发完整请求头。

## 3. 下载中心

### 3.1 现状（2026-11-16 基础完善）

- HTTP：真实 `URLSessionDownloadTask`，进度/速度/ETA、2xx 校验、文件名冲突、暂停/续传/停止/删除。
- BT：真实 Transmission JSON-RPC（session/torrent-add/get/start/stop/remove、409 重试、magnet/metainfo、files-wanted/unwanted），未检测到 daemon 时不落库。
- SQLite 持久化、启动恢复、添加/设置 sheet、完成文件播放、窗口中关闭继续下载。
- 系统入口：`magnet:`/`ddplay:`/`.torrent`；AppDelegate 打开/复用下载中心并预填；拖拽/剪贴板添加。
- BT 引导：检测/重试/复制安装命令/官网/RPC 设置/测试连接。
- 通知：完成/失败、点击定位任务、Dock badge、开关。
- 队列：HTTP+BT 统一并发、全部暂停/继续、按 infohash/hash/URL 去重。
- 状态：完成不可重启、缺失文件状态、HTTP 标题更新、无变化不刷 UI、多文件自然顺序播放、启动/暂停/删除竞态防护。
- 默认目录 `~/Downloads/AniXPlayer`；新增 `download.*` AX 标识。

### 3.2 仍待处理

1. **BT 开箱不可用**：仍依赖外部 `transmission-daemon`；没有内置引擎。发布前必须决策：外部 daemon 第一等公民，或捆绑 libtorrent/Transmission。
2. **HTTP 退出 App 即停止**：普通 URLSession，不是 background session；重启后从头下载。UI 已说明，但未做 background session/helper。
3. **边下边播仍不做**：没有本地 Range 代理/piece 感知；多文件播放已按自然顺序，但不是边下边播。
4. **无 RSS/自动下载/资源节点规则**；无任务重命名/复制源/历史。
5. **BT 文件选择只有 wanted/unwanted**，没有单文件优先级；做种/分享率策略未做。
6. **远程 Transmission** 的播放/Finder 路径映射未处理。
7. **远程 `.torrent` URL** 在 daemon 返回 hash 前只按 URL 去重。
8. 真实 Transmission/BT 尚未联调；随机崩溃/网络异常恢复仍需真实环境验证。

### 3.3 建议顺序

1. 真实 Transmission/BT 联调（转发端口、队列、文件选择、断线重连）。
2. HTTP background session/helper（或明确产品限制）。
3. RSS/自动下载/资源节点。
4. 做种/分享率/限速/任务重命名/历史。
5. BT 内核捆绑决策（GPL/体积/签名/公证）。

## 4. 本地媒体库

### 4.1 现状

不是壳，数据库/扫描/匹配/播放都是真的：

- SQLite + 文件夹 security-scoped bookmark、递归扫描、增量扫描、取消/进度、前 16MB MD5 + `/match`、海报墙、搜索/筛选、独立播放器播放、移除文件夹（只删索引）。
- 缺的是「媒体库体验」和「匹配控制」，不是数据骨架。

### 4.2 关键缺口（审计补充）

1. **匹配修正缺失**：重新匹配只处理未匹配文件；多候选/失败都丢弃；不能手动选番剧/剧集、不能改错配、不能取消匹配。
2. **重扫会清空匹配**：`makeScanned` 总是写 `isMatched=false`，文件大小/mtime 变化或缺失恢复后必须重新匹配。
3. **缺失文件不可见**：DB 有 `isMissing`，UI 没有过滤器/计数/清理/定位。
4. **重复/嵌套文件夹**：路径唯一但 folderId 会被最后一次扫描覆盖；父子文件夹同时添加会导致计数/筛选不稳定。
5. **无剧集分组**：一个文件一张卡；12 集会显示 12 张海报，播放顺序是 DB 顺序而不是剧集顺序。
6. **扫描取消不彻底**：递归枚举和 16MB hash 读取期间不检查取消；大目录/网络卷可能长时间无响应。
7. **无缩略图/时长/分辨率/元数据**；只有远程海报或扩展名占位。
8. **无排序 UI**（模型支持 title/fileName/fileSize/path，但 UI 固定 title）。
9. **无批量/多选**：点击卡片直接播放，不能批量匹配/移出/定位/重命名。
10. **性能/并发风险**：全量查询与全量 reload；播放前在主线程对全部文件做 `fileExists`；扫描/匹配状态可能互相覆盖；hash 等待信号量有潜在数据竞争。
11. **权限失效无重选引导**；文件夹菜单在扫描中仍可操作，存在 FK/竞态风险。

### 4.3 建议顺序

1. 匹配修正 UI + 重扫保留元数据 + 缺失文件管理 + 重复/嵌套处理。
2. 剧集分组/播放顺序 + 彻底取消 + 排序/多选/批量。
3. 缩略图/时长/分辨率 + 性能（分页/快照/后台 stat）。
4. 文件夹重扫/定位/权限重选/FSEvents。
5. 远程源暂不做，保留现有 SMB/WebDAV/FTP/Emby/Jellyfin。

## 6. 截图 / GIF 动图（会员）

### 6.1 现状

- 静态截图已完成：播放器截图按钮、预览、保存目录 bookmark、权限失败引导。
- **GIF MVP 已实现（2026-11-16）**：功能菜单「导出 3 秒动图」，从当前播放位置截取 3 秒、10fps、最大 480px，`AVAssetImageGenerator` + `CGImageDestination`，保存到截图目录并打开 Finder。
- 门禁已接：`EntitlementGate.require(.member, feature: .gifExport)`；静态截图保持免费。
- 首版只支持 AVFoundation 能解码的本地文件；远程流/不支持编码会明确提示。

### 6.2 后续增强

1. **抓帧内核**：当前 MVP 用 `AVAssetImageGenerator`，只支持本地 AVFoundation 能解码的文件；大量 MKV/HEVC/AV1 与网络源会失败。应改为复用 `MPVFrameRenderer` / `MediaThumbnailFetcher` 的无头 MPV 抓帧，AVFoundation 只做本地回退。
2. 选项 sheet：时长 1/2/3/5 秒、帧率 5/10/15、最大宽度 480/640/原尺寸；包含字幕开关。
3. 进度/取消/媒体切换取消；当前 progress 闭包为空，`Task.checkCancellation` 在 GCD 块里没有实际取消路径。
4. 预览与另存为；失败/取消/无权限状态细化（现在只有 2 秒 HUD）。
5. 输出 WebP/APNG；可加片段裁剪（起止时间）与画质档位。会员文案目前写「GIF、WebP 或 APNG」，在实现前要改成实际能力。
6. 弹幕默认不烧录；若产品要求，需离线弹幕合成器，不能依赖屏幕截图。
7. 流媒体/远程源回退或明确提示；避免大内存占用（限制帧数/尺寸/分块编码）。

## 8. 验收边界

- 每阶段必须 macOS Debug 编译通过；共享代码改动再跑 iOS/tvOS。
- 在线源不内置第三方站点；用户导入/配置，失败不伪造结果。
- BT 未配置/未安装时继续明确提示，不创建假任务。
- 会员门禁以服务端权益为准；GIF/在线观看/嗅探均走统一 `EntitlementGate`。
